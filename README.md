# BlackJack

Características implementadas:
Juego completo de BlackJack con todas las reglas solicitadas

Interfaz intuitiva con botones para iniciar, pedir carta y plantarse

Visualización de cartas con colores según el palo

Lógica correcta para el cálculo de puntuaciones (incluyendo Ases como 1 u 11)

8 casos de prueba que cubren todos los escenarios solicitados

Sistema de racha de victorias para el caso de prueba #6

Sin dependencias externas - solo HTML, CSS y JavaScript vanilla
